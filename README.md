# ADRs

Architecture Decision Records for the codellm-devkit project.

## Conventions

- One file per decision, numbered sequentially (e.g. `0001-xxx.md`).
- Each ADR follows the standard template: Title, Status, Context, Decision, Consequences.
- Statuses: `proposed`, `accepted`, `deprecated`, `superseded by ADR-XXXX`.
